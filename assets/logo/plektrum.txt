# Das Zeichen: ein Plektrum, als Pixelbild auf 32 × 32.
#
# Dieselbe Sprache wie die Rangszenen und Aufnäher — die App ist inzwischen
# aus Pixeln gebaut, und ein glattes Vektorzeichen stand daneben wie aus
# einer anderen App. Die Regel von vorher gilt weiter: entschieden wird bei
# 48 px, und dort überlebt nur eine geschlossene Silhouette. Deshalb keine
# Binnenzeichnung, nur Licht von oben links und Schatten unten rechts — die
# Stufen der Kante tragen den Pixel-Charakter, nicht ein Muster im Inneren.
#
# Die Kontur ist ein 351er wie zuvor: breite, flache Schultern, eine Spitze —
# 20 × 20, spiegelgleich. `tools/icons.mjs` erzeugt daraus
# public/icons/, `tools/readme-bilder.mjs` den Banner der READMEs.
#
# . #0c0c0e  Grund
# a #e8a23d  Bernstein
# h #f5c56a  Licht
# w #fff1cf  Glanz
# d #c98526  Halbschatten
# s #9c5f17  Schatten
